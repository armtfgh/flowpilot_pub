# Documentation images

## `flowpilot-architecture.png`

The unchanged Figure 1 image from the authors' manuscript **Agentic design of continuous flow processes with chemical knowledge and laboratory constraints**, manuscript revision dated 6 October 2026. The source image is 4414 × 3702 pixels. It is project-authored scientific artwork, not a newly generated interface mockup.

The illustration summarizes the planning, knowledge and specialist-review architecture. Its recipe card, candidate count and revision budget are schematic, not common settings for every campaign. “Validation” and “execution approval” in the figure refer to computational checks and internal selection, not experimental performance or authorization to operate laboratory equipment.

The historical count of 464 describes valid extracted records. It must not be substituted for the 437 indexed records or 115 indexed paired records in the research corpus. The approximate handbook count is illustrative; the audited rule-base export traces to six source texts. These resources are not bundled with this public source release.

No separate image license is granted by this file. The repository's [license remains undecided](../licensing.md).
